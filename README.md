# Safarnama

A night on the 12313 Sealdah–New Delhi Rajdhani, Asansol to New Delhi, told in 15 engraved stamps. Scroll to drive the train.

Live page: https://siddhant-kushwaha.github.io/safarnama/

- `index.html` and `art/` are the whole site; there is no build step to host it.
- `src/` holds the template, script and route data that `index.html` is assembled from.

Stamp art generated with Frameo. Halt times from the current timetable; pass-through times are estimates scaled from the open datameet/railways dataset. Station facts from Wikipedia.
